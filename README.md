# ActionScript 2 Library

[![License](https://img.shields.io/badge/License-Proprietary-red.svg)](https://github.com/Fallen01135/library-ActionScript2-Skyrim/blob/main/LICENSE)
![Platform](https://img.shields.io/badge/Platform-Windows-blue.svg)
![Game](https://img.shields.io/badge/Game-Skyrim_SE/VR-blue.svg)

A UI library for Skyrim SE/VR menu mods, written in ActionScript 2 on top of Scaleform GFx.
I use it in my own menu mods (e.g. Modern Wait Menu) and extend it as I go.

> **Status:** Work in progress. Some parts may not work yet, and the license will change once the library is more stable.

## What's inside (Custom Code)
- `source/Library/FTA/`: Some Utilities, including a Data Loader for ini files and json files.
- `source/Shared Elements/`: reusable UI elements shared between my menus
